# MechaTrack ⚙️

**An engineering student dashboard built with HTML, CSS, and JavaScript.**

MechaTrack is a personal project designed to help engineering students organize their academic work, monitor progress, and manage practical projects in one place.

## Features

- **Course Management:** Add and remove courses.
- **Task Management:** Create tasks, assign them to courses, and mark them as completed.
- **Progress Tracking:** Monitor task completion with a progress percentage.
- **Project Management:** Create projects, update their statuses, and track progress.
- **Project Analytics:** View project totals, completed projects, active projects, and average progress.
- **Local Data Storage:** Save courses, tasks, and projects in the browser using Local Storage.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `Index.html` in your browser.

No backend server is required for the current version.

## Project Status

MechaTrack is under active development. Future plans include improving the interface, learning backend development with Python and FastAPI, and exploring database integration with SQLite.
